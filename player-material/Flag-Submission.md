# Flag Submission

## Formats

- **Genuine flags** look like: `SYN{...}`. There are **5** of them,
  worth points.
- **Decoy flags** look like: `FFLAG:...`. There are **10** of them.
  They are real things you can find and decrypt, but they are
  deliberately wrong turns — **they award 0 points**. Finding one isn't
  a mistake; submitting one just won't score.

## Scoring

| Flag | Points |
|---|---|
| Original Flag 1 | 100 |
| Original Flag 2 | 100 |
| Original Flag 3 | 150 |
| Original Flag 4 | 200 |
| Original Flag 5 | 250 |
| **Total** | **800** |

## Important: Original Flag 3 is special

Original Flag 3's decrypted value is **not just a flag to submit** — you
also need to **keep it**. It's the password for something you'll need
much later, near the end of the challenge. (It is not any Linux
account's login password.)

## How to submit

Ask your instructor how flags are collected for your event (a form, a
scoreboard, or handed to them directly). This project does not run a
public scoring server — your instructor validates flags locally.
